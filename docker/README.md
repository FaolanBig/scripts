to quickly install the Docker Engine on Ubuntu, execute the [install_docker_latest.sh](./install_docker_latest.sh)by running one of the following commands in your terminal:
- `curl -L https://docker-install-script.bigvault.cloud | bash`
- `wget -qO- https://docker-install-script.bigvault.cloud | bash`

> ℹ️ bash must be installed on your machine and available in `/bin/bash`
